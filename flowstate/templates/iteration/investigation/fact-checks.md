# 事实核查记录

> 本文件用于记录调研阶段的关键断言和证据核查状态。
> 详细规范见 `fst-research` 技能和 `investigation-fact-check.schema.json`。

## 断言清单

| 断言 | 证据来源 | 推理过程 | 状态 | 置信度 | 过期时间 |
|------|---------|---------|------|--------|---------|
| | | | | | |

## 状态说明

- **PENDING**：待核查，证据来源可靠，但需要进一步确认
- **VERIFIED**：已验证，经过多重证据确认
- **DISPUTED**：存疑，证据冲突或不充分
- **OBSOLETE**：已过时，超过过期时间，需要重新核查

## 置信度评估

| 置信度 | 含义 | 提升条件 |
|--------|------|---------|
| 0.9-1.0 | 高度可信，多重证据支持 | 可直接提升 |
| 0.8-0.9 | 可信，证据充分 | 可提升，建议补充证据 |
| 0.6-0.8 | 一般，证据部分支持 | 需补充证据后提升 |
| 0.4-0.6 | 低，证据不足 | 不可提升，需进一步调查 |
| 0-0.4 | 很低，几乎无证据 | 不可提升，需重新调查 |

## 提升条件

只有当所有「存疑」项少于总项数的 5%，且所有「待验证」转为「已验证」后，
才能将调研结果提升为定稿文档。

## 使用说明

1. 在调研过程中，将关键断言记录到本文件
2. 为每个断言提供证据来源和推理过程
3. 评估置信度（0-1）
4. 设置过期时间（证据有时效性）
5. 审核完成后，通过 `/fst-promote` 提升为定稿文档
