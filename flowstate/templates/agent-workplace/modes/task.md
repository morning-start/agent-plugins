# Task 模式

> 适用：计划已定、按清单推进的阶段。
> 核心：**编号 + 勾选 + 分阶段分批**，每批可独立验证，控制权在人。

## 流程

1. **写任务清单**：`docs/task/TASKS.md`——编号列表 + 复选框（`- [ ]`）
2. **分批**：按**内聚程度**（同模块/同层）与**实现顺序**（先依赖后上层）分批次，
   批次间递进有序、每批可验证（编译/冒烟）
3. **逐批执行**：
   - 一次只做一批（"完成 TASKS.md 中 1~2 批并打勾"）
   - 每批完成：更新勾选状态 + 跑验证 + 向用户同步
   - 每批后审查（对照 plan / spec / DoD）
4. **控制节奏**：任务暴露意外复杂度时，先更新清单（加子任务）再继续

## 产物

`docs/task/TASKS.md`（任务 id 如 `P1-B1-T01`：phase-批次-任务）

## 关联

- 与 Spec 模式的 `tasks.md` 区别：Spec 面向"对齐验收"，Task 面向"执行勾选"；
  两者可共用——Spec 定稿后转成 Task 清单执行。
