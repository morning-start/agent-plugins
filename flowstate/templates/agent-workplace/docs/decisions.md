# 决策记录（Decisions）

> 记录重要取舍：**背景 → 选项 → 选择 → 理由 → 否决项**。
> 只记录值得回看的决策；琐碎选择不记。定稿后由用户决定是否提升到正式 `docs/`。

## DEC-001 示例

- **日期**: 2026-08-08
- **背景**: 需要决策的场景描述
- **选项**:
  - A：方案 A（优点/缺点）
  - B：方案 B（优点/缺点）
- **选择**: A
- **理由**: 一句核心原因
- **否决**: B（因为……）

## 约定

- 编号递增（DEC-001、DEC-002…）
- 一条决策一个小节，宁可短不可空
