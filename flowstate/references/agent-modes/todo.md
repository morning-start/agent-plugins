# Lightweight todo 路径（简单任务直接做）

> 定位：**一句话能说清 diff 的简单任务**直接做，不进重型方略，用轻量清单跟踪；代码执行入口仍是 `fst-iterate`。
> 是门槛最低的轻量路径，用于改动极小、无需规划、无需多步骤编排的任务。

## 是什么（本质）

对「改一个值 / 加一行日志 / 重命名变量 / 单点小修」这类无需规划、无需分批的任务，
跳过计划与任务拆分，直接列轻量清单 → 完成 → 最小验证。核心是**不为一句话能说清的事套流程**。

## 何时选用

- 改动能用**一句话说清 diff**
- 单文件、单点、无需探索方案

**反例**：改多文件、方案不确定、需探索 → 转 **Spec / Loop / Graph 模式**，或先规划再动手。

## Iron Law

改小 ≠ 不验证：即使改动再小，构建 / 冒烟的最小验证也不能省。

## 执行步骤

1. **判断**：这个改动能否用一句话说清 diff？
   - 能 → 交给 `fst-iterate` 走最小执行路径
   - 不能（改多文件、方案不确定、需探索）→ 转更重的模式或先规划
2. **列轻量清单**：编号 + 一句描述
3. **直接做**：逐个完成，勾选核销
4. **最小验证**：改动虽小，仍要做构建 / 冒烟的最小验证

## 产物

轻量 todo 清单（会话内或文件均可）。

## 与其他模式的关系

- 与 **Spec**：spec 是「任务可逐项验收」，todo 是「不用想就能做」
- 与 **Loop**：loop 是「目标循环逼近」，todo 是「一次做完」
- 与 **Graph**：graph 是「依赖图编排」，todo 是「单一动作」
