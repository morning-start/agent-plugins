# /fst-init — 立项初始化

启动 flowstate 立项流程（N1 立项 / N2 冻结 / N3 设计）。加载并遵循 `skills/fst-init/SKILL.md`。

## 步骤

1. **访谈 3 条核心底线**（一次一问，不脑补）：解决什么问题 / 目标用户是谁 / 必须上线的基础价值
2. **收集已知需求 + 标记未知**：显式标记「待确认需求」到 `known_gaps`
3. **需求分层**：刚性核心 / 弹性细节 / 临时新增 → 生成需求分层清单（schema 5.1）
4. **冻结范围**：生成迭代范围说明书（schema 5.2），用户签署后才进入设计
5. **柔性设计**：主干冻结 + 柔性预留（可配置化/参数化/状态预留），产出柔性 PRD
6. **产出**：需求分层清单、范围说明书、风险清单（schema 5.1/5.2/5.5）写入正式 `docs/`

## 规则

- 3 底线未书面确认 → 不得进入需求整理
- 范围说明书未签署 → 不得进入方案设计
- 未确认需求只做占位说明，不脑补补全

## 下一步

立项完成（底线确认 + 范围签署 + 柔性 PRD 通过）→ `/fst-iterate` 进入迭代开发；迭代中变更 → `/fst-change`。
