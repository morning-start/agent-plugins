# /pf-intent — Intent clarification

Load and follow `skills/pf-intent/SKILL.md`:

1. Interview the user one question at a time (core functionality, goal, scenarios,
   users/triggers, boundaries, platforms, complexity signals). Record answers verbatim.
2. Write the one-page PRD from the template in the skill.
3. Apply the complexity gate (Light / Medium / Heavy) and report the routed path.
4. Get explicit user sign-off before finishing.

Rules: no PRD → no design; never paraphrase user answers before confirmation.
