# MoonBit 技能编排

## 入口

所有用户请求从 `SKILL.md` 进入。入口职责：

1. **分类** — 根据用户输入判断项目类型和需求
2. **路由** — 将请求转发到对应的子技能
3. **追踪** — 记录当前管线状态

## 分类矩阵

```
用户输入
    │
    ▼
┌── 关键词匹配 ─────────────────────────────────┐
│                                                │
├─ "build" "create" "new" "写" "做" "开发"       │──→ 开发管线
├─ "debug" "fix" "error" "fail" "不工作" "bug"  │──→ debug 技能
├─ "review" "check" "audit" "quality" "审查"    │──→ review 技能
├─ "security" "vulnerability" "safe" "安全"     │──→ moon-audit 技能
├─ "publish" "release" "deploy" "发布"          │──→ publish 技能
├─ "test" "verify" "测试" "验证" "pass"         │──→ evaluate/verify 技能
└─ 其他                                          │──→ 问用户
```

## 开发管线（完整流程）

```
用户说"我要做 X"
    │
    ▼
┌──────────────────────────────────────────────┐
│ clarify(SKILL.md) — 需求澄清                  │
│ 输入: 用户原始描述                             │
│ 输出: project_type + 需求文档                  │
│ 路由: → design                                │
└──────────────────┬───────────────────────────┘
                   ▼
┌──────────────────────────────────────────────┐
│ design(SKILL.md) — 架构设计                   │
│ 输入: project_type + 需求文档                  │
│ 输出: 架构决策 + API 设计                      │
│ 路由: → scaffold → implement                  │
│ 用户介入: 选择架构模式 + 设计 API              │
└──────────────────┬───────────────────────────┘
                   ▼
┌──────────────────────────────────────────────┐
│ scaffold(SKILL.md) — 项目脚手架               │
│ 输入: project_type + 包名                     │
│ 输出: 项目骨架 (moon.mod.json + src/)          │
│ 路由: → implement                             │
│ 验证: moon check + moon test                  │
└──────────────────┬───────────────────────────┘
                   ▼
┌──────────────────────────────────────────────┐
│ implement(SKILL.md) — TDD 实现                │
│ 输入: 任务列表 + API 设计                      │
│ 输出: 完成的代码 + 通过的测试                   │
│ 路由: → review 或 → debug (失败时)            │
│ 验证: moon fmt --check + moon check + moon test│
└──────┬───────────────────────────────────────┘
       │
       ▼ (失败 3 次)
┌──────────────────────────────────────────────┐
│ debug(SKILL.md) — 自动调试                    │
│ 输入: 失败信息                                 │
│ 输出: 修复后的代码 + 验证                       │
│ 路由: → implement (重试)                      │
│ 验证: moon test -f <test_name>                │
└──────────────────────────────────────────────┘
       │
       ▼ (实现完成)
┌──────────────────────────────────────────────┐
│ review(SKILL.md) — 代码审查                   │
│ 输入: 完成的代码                               │
│ 输出: 审查报告 + 自动修复                       │
│ 路由: → verify                                │
│ 验证: moon check + moon info                  │
└──────────────────┬───────────────────────────┘
                   ▼
┌──────────────────────────────────────────────┐
│ verify(SKILL.md) — 验证门禁                   │
│ 输入: 审查后的代码                             │
│ 输出: 验证结果                                 │
│ 路由: → evaluate 或 → publish                 │
│ 验证: moon fmt + moon check + moon test       │
│       + moon info + moon-audit pipeline       │
└──────────────────┬───────────────────────────┘
                   ▼
┌──────────────────────────────────────────────┐
│ evaluate(SKILL.md) — 评估验收                 │
│ 输入: 验证结果                                 │
│ 输出: 用户判断 "好了" 或 "再改"                │
│ 路由: → publish (通过) 或 → implement (再改)  │
│ 用户介入: 判断质量是否达标                      │
└──────────────────┬───────────────────────────┘
                   ▼
┌──────────────────────────────────────────────┐
│ moon-audit(SKILL.md) — 安全审查               │
│ 输入: 项目路径                                 │
│ 输出: 安全扫描报告 (14 CWE)                    │
│ 路由: 独立运行，或由 verify 调用               │
│ 验证: moon-audit pipeline .                   │
└──────────────────────────────────────────────┘
                   ▼
┌──────────────────────────────────────────────┐
│ publish(SKILL.md) — 发布准备                  │
│ 输入: 验证通过的代码                           │
│ 输出: README.mbt.md + CI 配置 + 发布就绪      │
│ 路由: 完成                                    │
│ 验证: moon fmt + moon check + moon test       │
│       + moon-audit pipeline                   │
└──────────────────────────────────────────────┘
```

## 独立技能（单次调用）

以下技能可独立调用，不依赖开发管线：

| 技能 | 触发场景 | 输入 | 输出 |
|------|---------|------|------|
| `debug` | 测试失败、类型错误、运行时崩溃 | 失败信息 | 修复后的代码 |
| `review` | 代码审查、质量检查 | 代码 | 审查报告 |
| `moon-audit` | 安全审计、漏洞扫描 | 项目路径 | 安全报告 |
| `verify` | 验证门禁、格式检查、类型检查 | 项目路径 | 验证结果 |
| `evaluate` | 评估验收、是否达标 | 验证结果 | 用户决策 |
| `publish` | 发布准备、文档生成、CI 配置 | 项目路径 | 发布就绪 |

## 回落链

当某个技能不适用时：

```
技能不适用
    │
    ├── 有替代技能 → 切换到替代技能
    ├── 有降级方案 → 执行降级方案
    └── 无替代 → 问用户
```

例如：
- `moon-audit` 未安装 → 跳过安全审查，提示用户安装
- `c-ffi` 项目无 C 编译器 → 提示安装 GCC/Clang，中止
- `wasm` 项目无 WASM 运行时 → 提示安装 wasmtime，继续
